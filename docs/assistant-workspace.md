# 星丛与流萤集工作空间

助手可在已配置的工作空间内列目录、检索文档、分段读取、创建目录与文档、精确替换/追加/完整写入、重命名、移动和删除文档。不会操作工作空间之外的内容，不支持删除目录。原生工具调用中的临时目录 ID 只在本轮有效，提交时统一映射为实际节点 ID。

所有写操作先暂存，按本轮“允许保存文件与目录操作”选择自动提交或审阅后提交。保存前重新校验安装状态、工作空间、每份已有文档的版本、父目录关系、总配额与节点数量，然后在一个 SQLite 事务内提交；任一冲突或配额不足均不会留下部分目录或删除。支持目录依赖和多段读取的覆盖范围，未完整读取的文档不能整体覆盖。删除文档保留对话中可审阅的操作记录，清理导入资源前检查其他文档引用。

预览列出新增目录、新建文档、修改及删除，展示目录位置与 Markdown / LaTeX。保存事件刷新流萤集及星丛的参考文档列表。密钥仍只用于已保存接口，目录与文档的内容不能扩展工具权限。
