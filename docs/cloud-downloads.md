# 留痕下载 · 网盘使用指南

此功能使用网盘原有账号与权限。登录只是取得访问权限，并不会自动解析文件。

1. 在“留痕下载”展开“网盘下载”，选择网盘，点击“打开网盘助手”。也可填写有效分享页面地址。
2. 在独立窗口登录，进入文件列表或分享页，按网盘要求填写提取码，勾选文件。
3. 点击页面中的 LinkSwift / 下载助手按钮，执行解析。部分网盘会把入口放在文件列表上方或右键菜单。
4. 解析后选择 Aria2 下载时，破晓会接管 `aria2.addUri` 请求并交给本机下载，无需安装 Aria2。仅支持添加下载，不开放本机 RPC。
5. 也可在解析结果中复制文件的 **HTTPS 下载直链**，展开左下角“破晓 · 网盘助手”，点击“粘贴已解析直链并下载”，填入直链并点击“开始下载”。如果网盘要求来源校验，填写原网盘页面地址。
6. Windows 按提示选择文件保存位置；Android 在系统下载通知中查看。Windows 返回软件后可刷新“本机下载”查看进度。

网盘首页、分享页面、提取码都不是下载直链。直链失效时，回到文件列表重新解析。直链可能依赖当前登录 Cookie、来源页面、会员、设备或网络；破晓使用当前设备的隔离网盘会话，不会把登录信息上传到服务端。

如果某网盘没有出现 LinkSwift 入口，先刷新网盘页面，确认已进入受支持的文件列表。平台页面或接口变动仍可能影响解析。不要反复点击启动下载：新表单会显示提交结果，文件下载进度由保存窗口或系统下载通知确认。

网页版不能向其他网盘注入脚本，可使用 Windows / Android 客户端，或自行安装上游 [LinkSwift](https://github.com/hmjz100/LinkSwift)。
