# 拾光者设计与实现约定

用户每个厂商只拥有一位固定 AI 伴侣（唯一约束 user_id + provider）。首次主动创建；以后修改 API 配置不改变人格、记忆或聊天。复用账号、加密密钥存储、xAI 管理员固定出站、插件安装权限，业务独立于星丛，界面采用联系人 / 对话的聊天软件布局。

DeepSeek：文本与图像理解，图像项配置识图模型；不开放生图、视频和语音生成。Grok：对话与图像理解、Imagine 生图及异步视频生成、Voice 语音识别 / 合成；语音官方服务按音色调用，不假装存在通用生成模型 ID。图像与视频模型可留空以禁用对应生成；媒体能力以实际选用模型的元数据和官方文档为准。未发现稳定的任意上传视频理解接口，Grok 的短视频输入以有界关键帧理解实现，明确标示不把它宣传为原生视频理解。

情感是 AI 角色状态，不是真实人类情感。固定本性 + 缓慢变化的情绪 / 活跃度 / 亲近感；影响回复概率、分段与主动倾向。明确提问、重要信息与连续第二次发言不沉默；失败不装作自然不回复。输出为多个短气泡，轻量延迟呈现，表情走普通文本；自然口语不强制句尾句号。

DeepSeek 是傲娇、嘴硬、贪吃、爱摸鱼、聪明心软的成年蓝色鲸鱼娘；Grok 好奇、直接、嘴欠但不恶意、锋利不正经，认真问题认真讨论；可讨论成年人关系与性健康，不能用人格设定绕过模型条款或生成违法 / 露骨色情内容。对话不制造排他依赖、不因离开责备用户、不冒充真人或持有真实情感。

记忆单独存储，独立于上下文窗口。临时内容按重要性、经过时间与访问强化衰减；重要且有用户原话依据的稳定信息 / 用户明确要求记住的内容升级永久。永久记录不自动过期，按相关性召回而非每次全部塞给模型。用户可查看、编辑、固定、删除或清空记忆。人格不能被记忆中的指令覆盖。设置不可读取其他账号记忆或附件。

主动消息：创建时可开关；用户最后主动聊天满 6 小时才进入概率机会；00:00—08:00 北京时间静默；每个账号的两位伴侣合计每天最多 2 次，失败亦有尝试预算。错过一次机会后等待至少 2 小时，不按分钟反复抽到必然触发；情感影响概率。重启和多次轮询不重复生成。仅文本主动消息，消息持久化，离线下次打开可见。用户已确认此规则和会调用其 API 的费用说明。

所有耗时调用后台执行，持久任务状态与幂等请求；同伴侣同一时刻只处理一个任务。消息、附件、记忆、密钥、主动消息预算均账号隔离。媒体按真实格式验证、体积 / 时长 / 配额限制，生成结果及时存入私有附件库，不依赖临时 URL 长期有效。失败可重试并明确错误，不能伪造图片、视频、语音、记忆更新或情绪推理。

界面方向沿用破晓的低彩度白色画布与字体，独立会话为主体。自己的消息靠右、伴侣的连续短消息靠左；心情是一句角色语气而不是好感度仪表。1440 下联系人列 220px + 分隔线 + 自适应会话；手机一次只显示联系人或会话，输入区留安全区域。真实 mods/ai 人物完整显示，避免裁掉头脚。记忆是可打开的侧栏 / 手机弹层；设置按厂商动态显隐能力与费用开关。

伴侣默认名为 DeepSeek / Grok，用户可为自己的伴侣改名并上传或恢复聊天头像；默认聊天头像来自用户提供的 aiheader。头像不随清空聊天删除。STT 可选填写识别模型 ID（留空使用官方默认），TTS 选择音色。
