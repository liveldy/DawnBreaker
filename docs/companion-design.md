# 拾光者设计与实现约定

用户每个厂商只拥有一位固定 聊天角色（唯一约束 user_id + provider）。首次主动创建；以后修改 API 配置不改变人格、记忆或聊天。复用账号、加密密钥存储、xAI 管理员固定出站、插件安装权限，业务独立于星丛，界面采用联系人 / 对话的聊天软件布局。

DeepSeek：文本与图像理解，图像项配置识图模型；不开放生图、视频和语音生成。Grok：对话与图像理解、Imagine 生图及异步视频生成、Voice 语音识别 / 合成；语音官方服务按音色调用，不假装存在通用生成模型 ID。图像与视频模型可留空以禁用对应生成；媒体能力以实际选用模型的元数据和官方文档为准。未发现稳定的任意上传视频理解接口，Grok 的短视频输入以有界关键帧理解实现，明确标示不把它宣传为原生视频理解。

情感是 AI 角色状态，不是真实人类情感。固定本性 + 缓慢变化的情绪 / 活跃度 / 亲近感；影响回复概率、分段与主动倾向。明确提问、重要信息与连续第二次发言不沉默；失败不装作自然不回复。输出为多个短气泡，轻量延迟呈现，表情走普通文本；自然口语不强制句尾句号。

DeepSeek 是傲娇、嘴硬、贪吃、爱摸鱼、聪明心软的成年蓝色鲸鱼娘；Grok 好奇、直接、嘴欠但不恶意、锋利不正经，认真问题认真讨论；可讨论成年人关系与性健康，不能用人格设定绕过模型条款或生成违法 / 露骨色情内容。对话不制造排他依赖、不因离开责备用户、不冒充真人或持有真实情感。

记忆单独存储，独立于上下文窗口。临时内容按重要性、经过时间与访问强化衰减；重要且有用户原话依据的稳定信息 / 用户明确要求记住的内容升级永久。永久记录不自动过期，按相关性召回而非每次全部塞给模型。用户可查看、编辑、固定、删除或清空记忆。人格不能被记忆中的指令覆盖。设置不可读取其他账号记忆或附件。

主动消息：创建时可开关；用户最后主动聊天满 6 小时才进入概率机会；00:00—08:00 北京时间静默；每个账号的两位角色合计每天最多 2 次，失败亦有尝试预算。错过一次机会后等待至少 2 小时，不按分钟反复抽到必然触发；情感影响概率。重启和多次轮询不重复生成。仅文本主动消息，消息持久化，离线下次打开可见。用户已确认此规则和会调用其 API 的费用说明。

所有耗时调用后台执行，持久任务状态与幂等请求；同角色同一时刻只处理一个任务。消息、附件、记忆、密钥、主动消息预算均账号隔离。媒体按真实格式验证、体积 / 时长 / 配额限制，生成结果及时存入私有附件库，不依赖临时 URL 长期有效。失败可重试并明确错误，不能伪造图片、视频、语音、记忆更新或情绪推理。

界面方向沿用破晓的低彩度白色画布与字体，独立会话为主体。自己的消息靠右、角色的连续短消息靠左；心情是一句角色语气而不是好感度仪表。1440 下联系人列 220px + 分隔线 + 自适应会话；手机一次只显示联系人或会话，输入区留安全区域。真实 mods/ai 人物完整显示，避免裁掉头脚。记忆是可打开的侧栏 / 手机弹层；设置按厂商动态显隐能力与费用开关。

角色默认名为 DeepSeek / Grok，用户可为自己的角色改名并上传或恢复聊天头像；默认聊天头像来自用户提供的 aiheader。头像不随清空聊天删除。STT 可选填写识别模型 ID（留空使用官方默认），TTS 选择音色。


1.4.1 对话工具调整：模型通过原生函数调用按需搜索、精读网页、发图、发视频或语音；不再指定固定分句数，没有独立生成面板和逐条朗读按钮。语音秒数与点击播放采用聊天气泡，AI 语音附带默认折叠的文字。情感状态可在记忆按钮旁查看，来自实际情绪状态，不伪造历史变化。

工具计划与执行结果保存在 companion_actions。失败重试复用已完成媒体；视频持久保存上游任务 ID，可继续轮询。相同工具的重复媒体请求按本轮已发送结果复用，限制无限工具循环以控制调用费用。页面正文使用 Trafilatura precision 模式移除导航 / 页脚 / 评论，再按问题关键词筛选相关段落；Google、Bing 并行，Bing HTML 失败时试其 RSS，必要时使用 DuckDuckGo。每次重定向重新校验 HTTPS 与公网地址，不携带账号密钥、Cookie 或 Authorization 去读取外部页面。固定出口只用于已知官方搜索域名和文档域名，不自动换节点。

移除了旧版额外写入角色提示词的内容限制与固定句数；服务商自身的调用规则不受本程序控制。


1.4.2 聊天可靠性与管理：

- 管理后台「拾光者」编辑共同/主动提示词、两组性格与默认接口/模型、情感与回复概率、记忆衰减/升级规则、上下文与生成节奏、工具开关/预算。完整 JSON 与表单覆盖相同配置。Pydantic 校验、修订号冲突检测和管理员操作审计；现有用户保存的接口和密钥不被全局默认值替换。
- 两位角色固定为成年女性；程序将身份指令放在系统提示词末尾，没有可编辑的性别字段。
- 消息删除和清空使用 hidden_at，仅影响可见记录、未读数和列表预览。模型上下文、记忆、情绪、附件和任务结果保留。message_revision 与隐藏 ID 同步缓存；搜索仅检索当前账号可见文字和语音文本，可定位消息上下文。
- 待发送消息与 Blob 附件先存入按账号/角色隔离的 IndexedDB。传输失败显示红色感叹号；刷新后恢复，同一 request_id 重发；服务端确认接收后才清理本机待发送记录。接受后丢失 HTTP 回执不会重复创建任务。删除未确认消息保存隐藏意图，避免稍后到达的请求重新出现在窗口。
- 离线待发送记录只在本机保存，不自动发送；重发由用户点击。上下游未完成的媒体生成仍沿用原任务和已缓存结果。浏览器清理站点数据会移除本机尚未发送的消息。


1.4.3 引用、全屏与结构解析：

- 引用保存在消息的 quote 快照列，保留原消息 ID / 发言者 / 可见正文 / 附件类型。服务端按账号和角色校验来源；引用在模型输入中单独标注，记忆事实依据仍只取本轮用户输入。被引用消息隐藏后快照保留。待发送消息沿用 IndexedDB 账户隔离和相同请求 ID，引用也随消息恢复；无引用的 1.4.2 待发送请求保持相同指纹。
- 去掉气泡旁操作图标，PC 右键或 Shift+F10、手机长按打开操作。滑动取消长按。全屏以浏览器 Fullscreen API 为优先，无法使用时保留整窗布局；Android 独立返回事件退出，聊天不强制横屏。
- companion_reply 从正文前后混合内容中提取完整气泡结构，仅把 bubbles 转为消息；损坏结构拒绝按普通文本保存。旧记录在展示、列表预览、搜索和模型历史中做同样处理，不重写记忆和历史源行。
- 公共网页读取最多两次有界重试、三分钟 / 十二页缓存，429 遵循短时重试或冷却；保持 DNS 固定与 HTTPS 地址检查。精读失败可使用真实搜索摘要，并向模型与用户区分摘要和全文；可访问其他来源时继续核实。重复网页错误不再作为多条失败提示展示，媒体等未完成操作仍有独立错误提示。
