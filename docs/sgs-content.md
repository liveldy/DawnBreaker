# 三国杀·珍藏阁

来源：[哔哩哔哩游戏三国杀 BWIKI 武将图鉴](https://wiki.biligame.com/sgs/武将图鉴)。图片和内容包数据保存在服务端，原始资料保存在被 Git 忽略的 `mods/SGSpackage`。源码仓库只提交导入工具与分类规则。资料、美术版权归各原权利方。

安装开发依赖后运行 `python scripts/prepare_sgs.py --browser`。浏览器方式使用已安装 Chrome 正常读取公开 MediaWiki API，每秒最多一次；不需要登录或提供 Cookie。也支持普通 HTTP 客户端方式。原始修订、分类查询、图片信息与图像均缓存，失败后可继续。站点拒绝访问时停止并等待恢复，不处理验证码。

导入使用 mwparserfromhell 读取嵌套模板，BeautifulSoup 清理展示文字，Pillow 校正图片方向并生成 360×540 卡面。完整原画以最大 1920 像素保留，不拉伸人物；卡面使用中性留边保持完整构图。

分类不是按页面标题猜测：交叉核对武将类别、`武将名` 属性、皮肤所属武将和实际模板。图鉴的分类索引有漏项，因此类别数量只作为来源记录，不作为完整性的唯一依据。

- 顶层为“三国杀”，下设界限突破、一将成名、限定专属、威系列、谋定天下、星河璀璨、群英荟萃、皮肤珍藏。
- 界限突破按标准、一将成名、星火燎原分系列；仅保留开服武将确有独立突破原画的卡片。来源没有单独的神话再临突破原画，按用户确认忽略该分册。
- 一将成名只收非开服武将经典形象，按年份分系列。
- 限定专属仅神武、祈福、隐山之玉、高山仰止、武庙；威系列按威震天下、君威盖世、片羽威凤分组；其他经典形象按原武将包子系列归档。群英荟萃排除开服武将。
- 其他皮肤按同名归组，初始经典/界限/国战形象不重复作为其他皮肤收录。测试武将、限时地主与喵喵杀不收录。
- 界限突破、一将成名及其他皮肤为 R；其他经典形象为 SR。卡包只配置实际存在的 R、SR，不设置空的 SSR 抽取概率。

`mods/SGSpackage/import-report.json` 保存实际数量、排除原因、缺图和未提供故事的列表。卡片保存来源页面、原图地址、姓名、皮肤名、画师、故事及可用的修订编号。皮肤未提供故事时使用其所属武将的经典故事，并在数据中标明来源；来源没有故事时不编造。

所有卡片和内部卡册均使用平台现有通用卡面、卡册树、抽取、重复分解、详情和离线缓存设计。
