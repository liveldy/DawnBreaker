# 暗格资料类型

暗格提供密码、卡包、个人信息册三类记录。卡包适合银行卡、信用卡、会员卡等号码资料；个人信息册可保存证件、联系方式、地址和单位。每种记录都支持备注和自定义字段，敏感字段默认隐藏。搜索在本机解锁后的资料中进行，列表只显示敏感号码的末四位。

三类记录使用同一份加密信封：PBKDF2-SHA256（600000 次）派生主密钥，AES-256-GCM 加密，账号 ID 用作附加认证数据。主密码和明文不发送到服务端，服务器仍只接收加密内容与版本号。保留 `dawn-vault-v1` 标记，以附加 `schema:2` 和记录类型兼容旧数据。旧记录自动识别为密码；无法识别的类型或损坏数据不会被覆盖。

复制、编辑、删除、加密保存与导出均在解锁后进行。可导出当前分类或全部记录，支持 JSON 和 CSV；导出为用户主动保存的明文文件。离开页面或闲置 10 分钟自动锁定。跨设备编辑冲突仍使用原有版本检查，禁止静默覆盖。
