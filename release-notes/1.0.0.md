破晓 1.0.0 正式版

- 按需安装签到、语录、任务、词汇、抽卡、音乐、视频下载、文档、AI 助手、密码箱和模型图鉴插件；账户数据在各端同步。
- 天眼支持手机横屏查看；全屏内始终保留退出按钮和操作提示，Android 返回键也可退出，退出后恢复屏幕方向。
- 星丛列表与配置页完整展示人物形象。选择模型系列后自动填写对应官方 API 基础地址与协议，仍可手动修改；切换系列时清除旧系列密钥，避免误用。
- Windows 语录与音乐控件支持“始终在前（置顶）”和“依附桌面（置底）”，分别保存选择。
- 保留客户端离线文档阅读、缓存音乐、缓存模型图鉴和卡册浏览，以及听曲时长持久化、联网去重补同步。
- 保留 Markdown / LaTeX 与免费 CPU OCR、AI 工作空间和长期记忆、端侧加密密码箱、自定义头像、卡片品质标识与重复分解、词汇复习与记忆词库。

安装：Windows 为便携 EXE，Android 为 APK。沿用应用标识和安装签名，覆盖安装保留账号与数据。Android 内部构建序号持续递增，界面版本统一显示为 1.0.0。客户端未提供正式版更新能力时，请从官网下载后覆盖安装。

验证边界：Android 自动化验证覆盖原生桥、横屏状态恢复、返回键、后台播放器和缓存；厂商后台策略及系统启动器兼容性仍需真机验收。
