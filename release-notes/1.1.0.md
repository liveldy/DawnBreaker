破晓 1.1.0

- 拾光记新增图书管理员、好助手、静观其变三个每日任务（各 5 日光精华），以及笔耕不辍、心灵的交流两组七阶段成就。文本按非空白字符的实际新增、删除、替换计数，无改动保存不计；成功助手回答按轮计数，网络重试不重复计数。
- 飞跃新增 Windows 客户端专用飞速记忆：学习 / 测试 / 复习的提示跟写和中译拼写，黑色全屏、即时拼写反馈、计时与练习结算；支持设置单词数、选择弦音余韵或本地节奏曲。词汇记录共用，输错如实记录。
- 流萤集的文本及 OCR 导入记录均可删除，保留已导入文档和图片；进行中的 OCR 需等识别完成。
- 星丛去除新建页形象灰边，新增图标 / 列表浏览；模型系列均使用英文名，手机用明确的模型选择框；对话可删除、归档、恢复。
- 管理员可按日期安排今天及未来的语录。未指定时随机选取，同一账号当天保持稳定，内容包权限仍有效。
- 天眼改为平台内原生页面，不再嵌套网页：排行榜、能力与成本图、API 监视依次纵向排列。仅能力图支持全屏，手机全屏横屏适配，通过 Android 返回键退出；桌面按 Esc 退出，无额外退出按钮。
- API 监视支持名称、基础地址、协议和加密密钥，查询模型、连通延迟、公开单价；DeepSeek / OpenRouter 提供各自开放的余额 / 密钥额度与消费。平台未开放的统计显示不可获取，并另外展示本程序真实推理请求和已报告 Token；支持主动小额推理测速和复制 API 密钥。
- 修复 Windows 收起到托盘后再次双击程序无法唤起的问题，主程序保持单实例，恢复已有窗口和焦点。

Windows 为便携 EXE，Android 为 APK；版本号 1.1.0，内部发布序号 / Android versionCode 为 8。沿用已有签名与账号数据，可覆盖安装或使用内置更新。官网仓库只存放官网文件，安装包在 GitHub Releases。

Android 原生返回键与方向恢复使用自动化测试验证；厂商后台、桌面启动器和真机旋转行为仍需实际设备验收。通用 API 密钥通常不能读取平台全量账单，空缺字段不会被估算为余额或零消费。
