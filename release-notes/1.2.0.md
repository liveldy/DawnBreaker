# 破晓 1.2.0

完整应用源码首次公开于 [liveldy/dawnbreaker](https://github.com/liveldy/DawnBreaker)，采用 AGPL-3.0-or-later。Windows、Android、服务端及共享网页界面置于一个仓库，原官网下载页仓库保持独立。

- 天眼默认显示模型名称，点击绘出斩杀线、区域和图内 / 全库斩杀数；排行榜增加官网链接。运营商预设自动填写基地址，增加 Kimi、302.AI 等官方余额和 OpenAI / Anthropic 管理密钥的组织近 30 天统计。无公开 API 文档的平台不列入。
- Windows 增加启动加载页，保留单实例托盘唤起；减少打包的无关依赖。
- 弦音余韵支持顺序播放、随机播放和单曲循环，Android 后台播放器同步遵守播放模式。
- 飞速记忆输错后自动删除错误后缀，加入持久历史与单词学习 / 测试 / 复习进度。默认按 50 词批次推进，完成三阶段各三轮及连续三天复习后进入下一批；可切换自由练习。
- 留痕视频下载更名为留痕下载。Windows / Android 使用独立网盘窗口适配 LinkSwift 1.1.3，覆盖其支持的八类网盘；解析后直接下载，或兼容 Aria2 添加任务。登录、会员和平台访问限制仍然适用。
- 新增折跃门：基于 Mihomo v1.19.33 的 Clash 兼容配置、订阅、代理模式、节点、测速与流量。Windows 可手动开启系统代理，停止后恢复原设置；Android 请求系统 VPN 授权后连接。
- 新增浮光掠影：本地图像、视频与 HTML / HTTPS 网页壁纸制作、壁纸包导入导出、电脑 / 手机分别适配；管理员可发布云端，其他用户可下载并本地使用。网页版提供客户端入口。

Windows 与 Android 安装签名及更新验证密钥沿用，内部发布序号为 9。Android 网页壁纸及隔离网盘窗口要求 Android 9+；其余功能保持 Android 6+。源码不包含用户账号、私钥、数据库、缓存和可选版权素材包。对应第三方许可证与源码说明随发布提供。
