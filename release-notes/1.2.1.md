# 破晓 1.2.1

在 1.2.0 的功能基础上，完善 Android 网盘助手的来源隔离：使用限定 HTTPS 网盘来源、仅接受主页面的消息通道，嵌入页面无法调用原生网盘功能。需要支持 Web Message Listener 的 Android System WebView，版本过旧时会提示先更新。

包含 1.2.0 的全部更新：天眼名称与斩杀图、运营商 API 监视、词汇批次与历史、音乐播放模式、留痕网盘下载、折跃门和浮光掠影。Android 壁纸状态通过跨进程文件同步，暂停与切换即时生效。

应用源代码公开于 [liveldy/DawnBreaker](https://github.com/liveldy/DawnBreaker)，官网仓库独立。Windows / Android 内部发布序号为 11，安装签名与更新验证密钥沿用，可直接覆盖更新。
