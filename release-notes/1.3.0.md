# 破晓 1.3.0

- 浮光掠影仅支持 Windows：网页壁纸支持桌面空白区域的鼠标交互，可选择显示器，适配多屏缩放与热插拔；需要键盘时可打开独立交互窗口。移除 Android 壁纸入口及系统服务。
- 折跃门改进首次初始化：随客户端提供已校验的规则数据库，保留规则提供器缓存，避免重复点击并延长初始化等待；Android 增加 DNS 初始化与连接生命周期处理。新增分组折叠、一键测速及进度。
- 修复网盘助手直链入口：使用可见下载表单，显示提交或错误结果。视频与网盘下载分为两个折叠区域，内置逐步使用指南。网盘会员、权限、直链有效期与平台限制仍适用。
- 星丛增加模型返回的思考内容和操作记录。支持通过受限工具读取、精确修改、新建工作空间文档，每轮完成后更新配置的记忆库；可选择自动保存或先审阅。保存前检查文档版本、权限和空间；停止或失败不会写入未完成修改。修复原始 JSON 回答与手机聊天记录布局。
- 流光笺按账号记录每日语录，可查看历史并选为今日内容；个人选择只影响本账号。升级前未知日期不补写虚构记录。
- 朝暮签新增私密每日记录与中国大陆法定节假日、调休标记，并提供国务院安排来源；尚未取得的年度安排会明确提示。
- 流萤集默认提供每账号 64 MB 空间，管理员可调整。支持上传图片并插入 Markdown，查看空间占用、管理未被引用的图片；识别导入和 AI 编辑共用空间限制。
- 官网恢复最初的分栏设计，介绍流萤集、星丛、飞跃及更多插件。

安装新版覆盖更新可保留账号与本地数据。Windows 仍采用单实例与托盘运行，Android 沿用既有应用签名。
