# 破晓 1.3.2

- 暗格新增卡包和个人信息册，与原有密码记录共同保存在主密码加密箱中。支持银行卡、会员卡、证件、联系方式、地址、备注及自定义字段；敏感号码默认隐藏，支持复制、搜索和按分类或全部导出。兼容旧密码记录，主密码和明文资料不发送到服务器。
- 新增“系统管理”插件，仅 Windows 与 Android 客户端可用。显示本机系统、处理器、内存、存储、屏幕及客户端信息；Android 另显示可用的电池数据。设备信息在本机读取，不上传服务器，离线也可使用。
- Windows 支持整理破晓客户端进程的可回收内存、打开任务管理器及系统设置；Android 支持请求回收本应用空闲内存，进入应用、存储与设备设置。操作不会关闭文档、音乐或 VPN；如未观察到占用下降会如实显示。

- 调整网页资源的编译目标，兼容较旧 Android WebView 的启动语法。

安装新版覆盖更新可保留账号、主密码加密资料与本地数据。系统管理原生能力需更新客户端后使用。
