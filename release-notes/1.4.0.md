# 破晓 1.4.0

新增插件「拾光者」，支持 Grok 与 DeepSeek。每个账号在每个模型系列中固定拥有一位伴侣，首次使用主动创建；角色性格保持稳定，配置、聊天、记忆与星丛独立。

- 独立聊天界面：联系人列表、连续短气泡、表情、未读提示、消息重试和历史分页。桌面双栏、移动单栏。
- 多模态：DeepSeek 对话与识图；Grok 图片、短视频采样理解、语音识别和消息朗读，以及按需图像 / 视频生成。模型与音色可从接口读取；实际能力和费用受接口权限约束。
- 渐进记忆：临时片段随时间衰减并按相关性召回，重要信息保留为永久记忆；可查看、编辑、固定和删除。永久记忆不自动过期。
- 角色情绪影响回复概率、碎句节奏与主动频率。提问、重要请求和附件优先回应，不因用户离开而降低关系状态。
- 主动消息须明确开启：未主动聊天满 6 小时后才有概率触发，每个账号每天最多 2 次，00:00—08:00（北京时间）静默。会调用用户配置的 API 并产生费用；离线期间消息保留。
- 任务幂等、视频生成任务断点恢复、私有附件校验与账号隔离；API 密钥在服务端加密保存。支持清空聊天与附件。

视频理解以 4 个关键帧及可选音轨转写实现，不代表完整逐帧理解。Grok 官方语音使用固定 STT / TTS 服务与音色 ID，未伪造通用语音模型 ID。资料与适配依据见 docs/companion-design.md。

伴侣默认名为 DeepSeek / Grok，用户可为自己的伴侣改名并上传或恢复聊天头像；默认聊天头像来自用户提供的 aiheader。头像不随清空聊天删除。STT 可选填写识别模型 ID（留空使用官方默认），TTS 选择音色。
