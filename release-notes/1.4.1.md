# 破晓 1.4.1

拾光者改进：

- 移除界面中的关系标签；由模型自行决定消息条数，保留不同性格和情绪节奏。
- 记忆按钮旁新增情感状态，查看心情、活跃程度与熟悉程度。
- 图像、视频和语音融入对话：直接提出需求，模型按需调用工具并发送；移除独立生成菜单和逐条文字朗读按钮。
- 语音改为常见聊天软件样式，显示秒数、点击播放 / 暂停。AI 语音附带默认折叠的文字内容，适合公共场合阅读。
- 图像和视频直接发送，不附加固定生成标签，可带自然评论；图片与大图预览均增加下载按钮。
- 新增 Google / Bing 多引擎搜索，Bing RSS 与 DuckDuckGo 备用。网页精读提取相关正文，过滤导航、广告与无关段落；回复可查看参考网页。
- 工具计划和媒体结果持久保存，重试复用已完成结果，视频继续原上游任务，避免重复生成计费。
- 移除旧版程序额外添加的角色内容限制提示词。服务商自身规则仍由接口提供方执行。

已有聊天、记忆、名称与头像保留。Windows / Android 客户端请更新到此版本以使用新界面。
